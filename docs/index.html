Roleplay Machine

Узловой клиент для ролеплея с ИИ. Память, которую ведёт сама модель, хроника сцен, критик ответа, кубик и сетевая игра в Telegram. Основа — движок SillyTavern.

Скачать Установка

Части партии

Карточка, промт, лорбуки, память и модель — отдельные ноды на холсте. Видно, что уходит модели и почему пришёл такой ответ.

Душа

Модель ведёт дневник, состояние сцены, факты мира и психологию персонажей

Хроника

Сцены сжимаются в главы, главы — в арки и эпосы

Критик

Заворачивает подлиз, безволие, игру за игрока и читы

Кубик

Исход брошен до сцены — модель не может его подменить

Что внутри

  • Память живёт в документах, а не в контексте
  • Консоль запросов: что ушло, сколько токенов, что вернулось
  • Свой лимит контекста и температура у каждой подсистемы
  • Сетевая игра в Telegram: у каждого живого игрока своя персона, память и состояние
  • Ветвление партии от любого сообщения
  • Каталог карточек: chub.ai, Character Tavern, RisuRealm
  • Работает на ПК и на телефоне в Termux

Установка

Один репозиторий, две сборки. Ключей и карточек внутри нет — вписываешь свои.

ПК · Windows

Полный набор, включая озвучку.

git clone https://github.com/Leosmaru/rlm
cd rlm/pc/server && npm install --omit=dev

Запуск — «Запустить RLM.bat». Холст: 127.0.0.1:8100/rlm/

Скачать ZIP

Телефон · Termux

Всё то же, кроме голоса.

pkg install -y git nodejs-lts
git clone --depth 1 https://github.com/Leosmaru/rlm
cd rlm/termux && ./install-termux.sh

Дальше запуск одной командой: rlm
