RLM

Roleplay Machine — узловой клиент для ролеплея с ИИ. Память, Хроника, Критик, честный кубик и сетевая игра на несколько живых игроков.

Windows. Полный набор, включая озвучку.

Скачать ZIP

Termux (телефон)

Всё то же, кроме голоса. Запуск командой rlm.

Инструкция

ПК — установка

git clone https://github.com/Leosmaru/rlm
cd rlm/pc/server && npm install --omit=dev

Запуск — Запустить RLM.bat в папке pc. Холст откроется на http://127.0.0.1:8100/rlm/

Termux — установка

pkg install -y git nodejs-lts
git clone --depth 1 https://github.com/Leosmaru/rlm
cd rlm/termux && ./install-termux.sh

Дальше — одна команда: rlm

Что внутри

  • Узловой холст — карточка, промт, лорбуки, API и опции собираются проводами, видно, что уходит модели.
  • Душа — ИИ ведёт память в документах: дневник, состояние сцены, факты мира, психология, темы.
  • Хроника — сцены сжимаются в главы лорбука и сворачиваются в арки и эпосы.
  • Критик — заворачивает подлиз, безволие, игру за игрока, разрывы логики и читы.
  • Рандомайзер — честный кубик: исход брошен до сцены, модель не может его подменить.
  • Сетевая игра — партия на несколько живых игроков через Telegram-бота, у каждого своя персона, память и состояние.
