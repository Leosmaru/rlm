# RLM — Roleplay Machine

Узловой клиент для ролеплея с ИИ: холст из нод, память Душ, Хроника, Критик, честный кубик,
сетевая игра на несколько живых игроков через Telegram.

В репозитории **две отдельные сборки**:

| папка | для чего |
|---|---|
| **`pc/`** | ПК (Windows): полный набор, включая озвучку |
| **`termux/`** | телефон (Termux): всё то же, **кроме голоса** — память, суммаризация, критик, эмбеддер работают |

Ключей и карточек в сборках нет. Пресета два: **Сингл игра** и **Сетевая игра**.

---

## ПК

```bash
git clone https://github.com/Leosmaru/rlm
cd rlm/pc/server && npm install --omit=dev
```

Запуск — `Запустить RLM.bat` в папке `pc`. Холст: `http://127.0.0.1:8100/rlm/`

## Termux

```bash
pkg install -y git nodejs-lts
git clone --depth 1 https://github.com/Leosmaru/rlm
cd rlm/termux && ./install-termux.sh
```

Дальше запуск одной командой:

```bash
rlm
```

## Первые шаги

1. Ключ провайдера — в ноду **API** (например OpenRouter).
2. Карточка персонажа — стартовое меню: «🖼 Из файла» или «🌐 Каталог сайтов».
3. Справка по всему приложению — кнопка **❓** в интерфейсе или **F1**.
