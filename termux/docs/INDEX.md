# RLM — Индекс документации («где что искать»)

> **Устав документа**
> - **Зачем:** карта — какой документ открыть под задачу. Точка входа во всю документацию.
> - **Что сюда пишем:** строку про каждый документ + когда его открывать.
> - **Чего НЕ пишем:** логи сессий, историю, детали реализации — **НИКОГДА**. Индекс должен оставаться маленьким.
> - **Правило ведения:** меняется только когда документ появляется или исчезает.

При поиске и разборе причин — **сначала сюда**, потом в нужный файл. Не сканировать весь код вслепую.

## Правила документации (кратко)

- У каждого документа сверху **устав** из 4 строк — соблюдается строго.
- **Состояние** (`architecture`, `formats`) = всегда «как есть сейчас», правится только где изменилось.
- **История** — только в `changelog.md`.
- Новый документ — только после явного подтверждения (что/зачем/почему существующие не годятся).

Полные правила ведения — в памяти проекта (`rlm-docs-rules`).
