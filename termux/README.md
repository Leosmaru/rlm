# RLM — Roleplay Machine (сборка для Termux)

Клиент для ролеплея с ИИ: узловой холст, память Душ, Хроника, Критик, сетевая игра через Telegram.
Эта сборка — **без озвучки** (голосовой сервис требует torch и на телефон не ставится). Всё остальное
работает: память, суммаризация, эмбеддер, критик, рандомайзер, переводчик.

## Запуск

Один раз — установка:

```bash
cd "termux rlm1"
./install-termux.sh
```

Дальше запуск откуда угодно **одной командой**:

```bash
rlm
```

Откроется сервер, в браузере телефона — `http://127.0.0.1:8100/rlm/`

## Что дальше

1. Вставь ключ провайдера в ноду **API** (например OpenRouter).
2. Загрузи карточку персонажа: стартовое меню → карточка → «🖼 Из файла» или «🌐 Каталог сайтов».
3. Справка по всему приложению — кнопка **❓** (или F1).

Пресетов два: **Сингл игра** и **Сетевая игра**.
