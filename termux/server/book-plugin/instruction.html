📕 Установка плагина «умная память»

Ставится по ссылке из GitHub прямо в SillyTavern. Серверную часть — один раз включить (ниже).

🧠 Умная память (Дневник души) — как модель это «вспоминает»

Кнопка 🧠 у палочки. Память — 4 дока на каждый чат, листаются ◄►. Разница — как каждый попадает в контекст модели:

  • 📔 Дневник ? — чувства персонажа → в промт последние по времени.
  • 🧠 Эмоции · ❤️ Отношения ? — текущее состояние → в промт всегда целиком.
  • 📚 Факты/темы ? — факты о мире → в промт 3 самые близкие по смыслу («из трёх в контексте»).

Итог: дневник — по времени, эмоции/отношения — всегда, факты — 3 по смыслу. «Что правда сейчас» решает не модель, а запись: Archivist перезаписывает тему на новую правду, поэтому нет каши «украли/вернули».

Установка серверной части (умная память)

Проще всего: 🧠 → ⚙ Настройки → секция «Установка сервера» → 📋 Копировать команду. Вставь в Termux (или ПК-терминал) и запусти:

mkdir -p ~/SillyTavern/plugins/soul-md && curl -o ~/SillyTavern/plugins/soul-md/index.js https://raw.githubusercontent.com/Leosmaru/SillyTavern-MachineMechanic/main/soul-md-server.js && sed -i 's/enableServerPlugins: false/enableServerPlugins: true/' ~/SillyTavern/config.yaml

Потом полностью перезапусти сервер ? (в Termux: pkill node → снова запусти).

Без этого кнопка 🧠 будет, но записи не сохранятся («сервер не сохранил»).

На ПК проще — без консоли: положи soul-md-server.js как plugins\soul-md\index.js через проводник, в config.yaml поставь enableServerPlugins: true (блокнотом), перезапусти. Команда выше — для телефона (Termux), где проводника нет.

Установка расширения — проще всего по ссылке (GitHub)

  1. SillyTavern → Extensions (кубики) → Install extension.
  2. Вставь URL репозитория: 
    https://github.com/Leosmaru/SillyTavern-MachineMechanic
  3. Install → F5. Весь фронт (кнопка 🧠, вьюер, настройки) уже работает.

Обновлять потом — кнопкой Update у расширения. Заодно приезжает файл soul-md-server.js (он в репо) — для серверной части.

Install по ссылке ставит только фронт. Серверную часть (умную память) включаешь один раз — см. раздел «Установка серверной части» ? выше.

После установки / обновления

Менял фронт → F5. Менял серверную часть → перезапуск сервера (Termux: pkill node → старт).
