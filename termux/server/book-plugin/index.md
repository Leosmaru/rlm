# Плагин «Механик машин» для SillyTavern

> Форк Memory Books. Значок 🔧 у волшебной палочки открывает полный интерфейс
> приложения **прямо в чате как сообщение**, целиком на русском. Плюс перевод
> сообщений через ИИ и система бросков кубика. Работает **без** отдельной Memory Books.

Репозиторий: https://github.com/Leosmaru/SillyTavern-MachineMechanic
Плагин: `C:\Tavern-1.14.0\data\default-user\extensions\SillyTavern-MachineMechanic\`

## Индекс документации
- **index.md** — этот обзор + индекс.
- **[guide-code.md](guide-code.md)** — техдокументация: архитектура, сборка, все
  доработки движка, рабочий цикл, диагностика.
- **memorybooks-docs.html** — HTML-справка (в плагине = `help.html`), к ней ведут
  значки «?» в интерфейсе. Держим актуальной под приложение.
- **instruction.html** — отдельная инструкция (не трогаем без запроса).
- **SillyTavern-MemoryBooks/** — исходный плагин-референс.

## Что умеет (актуально)
- **🔧 интерфейс в чате** — иконка у палочки рисует настоящий интерфейс приложения
  как сообщение в ленте; крестик/«Закрыть» убирают.
- **Русский принудительно** — независимо от языка SillyTavern.
- **«?» справка** — у каждой настройки; клик открывает `help.html` на нужном месте
  с подсветкой.
- **Маркеры сцены ◄►** — в видимой шапке каждого сообщения (не в скрытом меню),
  доступны на телефоне.
- **🌐 Перевод** — значок у сообщения переводит его через ИИ (перевод под сообщением);
  свой промпт, профиль подключения ST, своя температура (по галочке).
- **🎲 Кубик** — свой рандомайзер; режимы «число»/«успех-провал» (у каждого свой
  промпт); бросок скрыто уходит в промпт (ИИ учитывает) и рисуется над сообщением;
  разовый форс следующего броска; шкала критичности.
- **Стрелки ◄► у ножниц** — расширяют выделение текста для «Clip» на соседние сообщения.
- **🧠 Дневник души** — отдельная память **на каждый чат**: дневник + трекеры Psyche/Status
  (пишет модель раз в N ответов, N настраивается), поиск по смыслу родным эмбеддером ST,
  перевод доков через Яндекс. Кнопка 🧠 рядом с полосками; удалил чат — дневник чата стёрся.
  Нужен серверный плагин `plugins/soul-md` + `enableServerPlugins: true`.

## Быстрый старт
1. Установить по ссылке (SillyTavern → Extensions → Install extension → URL репозитория)
   или обновить (**Update**), затем **F5**.
2. Внизу у палочки — значок **🔧**.

## Дорабатывать
Правки исходников → пересборка → F5. Детали и команды — в [guide-code.md](guide-code.md).
```
cd C:\Tavern-1.14.0\data\default-user\extensions\SillyTavern-MachineMechanic
npm run build
```
